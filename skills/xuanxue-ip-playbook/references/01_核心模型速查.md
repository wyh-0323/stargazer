# 核心模型速查（回答任何问题前先对齐这里）

> 来源：反编自「一勾工作号」(yigou88) 16+ 篇公开教学。标注【观点】的是操盘手个人判断/有时效和招生立场，输出时表述为"经验判断"，不写成官方/必然结论。

## 一、定位与人设

### 1. 人×内容贴合感（最高原则）
- 爆的前提不是努力、不是设备，是**内容与你本人贴合**：风格 = 你的长相/气质 × 你的语气。
- 真实案例：同一场景同一博主，只改成贴合自己的讲法，400 赞 → 4 万赞。
- 用法：判断一个选题/人设能不能做，先问"这是不是我本人？我这样讲自不自然？"不贴合的内容，方法论再对也不出结果。

### 2. 面相/气质 × 话题 二维定位矩阵
|  | 现实向话题 | 唯心向话题 |
|---|---|---|
| **热感/亲和** | 美妆、减肥、穿搭 | 情感、关系（热感疗愈） |
| **冷感/距离** | 职场、商业、搞钱 | **玄学、命理、疗愈**（冷感专业） |
- 不要逆着自己的气质做：冷感的人硬演甜妹、热感的人硬装冷峻权威，都事倍功半。
- 占星/玄学天然适配"冷感 × 唯心"象限：专业、神秘、有距离感的可信度。

### 3. 人设是"长出来"的，不是造出来的
- 不要一开始就打造完美人设——越完美越装不下去、越容易翻车。
- 人设是在持续真实地发视频/直播中，由粉丝反馈帮你一点点确立的。先做、再根据反馈收敛。

### 4. 差异化标签公式
核心身份标签 + 与别人的不同点。可用素材：地域+从业年限+赛道（"在杭州做了10年高客单私域"）、收入跃迁（"从月薪3千到年入几百万"）、可验证的认知差/结果（带学员拿到的结果）。

## 二、内容类型（玄学号最关键，直接决定客户质量）

### 问题解决型 ✅ 要做  vs  情感共鸣型 ❌ 少做
| | 情感共鸣型 | 问题解决型 |
|---|---|---|
| 讲什么 | 是什么 / 现象 / 表现 / 情绪 | **为什么 + 怎么做** |
| 结构 | 给定义、贴标签、描述苦闷 | **70% 讲底层原理 + 30% 讲行动路径**，给独特洞察 |
| 吸引谁 | 20 岁左右低龄泛粉，看完骂两句很爽快 | **30+ 中女高净值客户**，要逻辑要答案 |
| 结果 | 有流量、无获客、只付低客单 | 精准客资、高客单信任 |

- 玄学三种**低获客浅内容（避坑）**：①大众占卜（几张牌怎么看）看热闹；②纯知识点罗列（"几宫落几宫=什么"）用户@AI自问自答；③星座男标签短解析（"摩羯男/天蝎男怎样"）有流量没获客。
- **高级讲法示范**（同一选题"怎么拿捏某类人"）：低阶="吃软不吃硬/情感淡漠"只给定义；高阶="这类人骨子里慕强，高主体性获偏爱＋以柔克刚满足征服欲，要一软一硬两手抓"——给反常识洞察。
- **模板平移法**：一个验证过的深度结构，可平移到任意玄学细分——星盘配置、星宿关系（安坏/危成）、八字日主（庚金/丙火/辛金）等都套同一"为什么+怎么做"骨架。

## 三、内容配比（先分工，再配比）

### 四类内容（底层分类）
1. **流量型**：破层级、被更多人看见（拓圈）
2. **人设型**：我是谁、我的经历与价值（建立认同）
3. **痛点型**：精准戳中可成交客户的问题（筛客）
4. **营销型**：产品、服务、好评（打消临门一脚）

### 3.1 先分工：老号是成交号，新号是流量号
- **老号**：1600 粉、月变现过万、每周稳定数人报课、不露脸、内容为教学视频＋占星题图文 → **成交号**。承担教学证明（真题试题、讲课录屏剪辑）与转化闭环，**不需要改**。
- **新号**：人设号、出镜、目标 = 占星获客 70% ＋ 学员转化 30% → **流量号**。承担前端拓圈，同时立两个身份（十年占星师 / 会教课的老师）。
- **铁律：不能用老号打法做新号。** 老号能跑通，是因为有 1600 精准粉＋图文题高收藏；新号没有这个基础，直接发垂直教学跑不动（实证：新号非明星选题只有几个到十几个赞）。
- 新号不剪教学视频（都是上课录屏），"我是老师"靠**讲得清楚本身**证明，不靠晒。

### 3.2 新号冷启动配比 6:2:1:1
| 层 | 占比 | 作用 | 例 |
|---|---|---|---|
| 泛人群拓圈 | 60% | 破层级、拿新流量 | 母爱的三种形状、分手后走不出来 |
| 咨询获客 | 20% | 精准戳可成交客户 | 咨询里被问最多的一句话 |
| 学员入口 | 10% | 证明"我会教" | 塔罗师转占星、80 分及格 |
| 人设 | 10% | 立十年占星师 | 我为什么这么要求学员 |

- 老号沿用原配比：**拓圈 60–70% ＋ 变现 30%**（因为已有转化闭环）。
- 高客单是长周期、多触点决策，靠内容矩阵持续养，不指望一条视频成交。

### 3.3 关键：泛人群里至少一半要是"急性需求"
**急迫性决定付费意愿。** 这是选题的硬标准。

| | 慢性洞察 | 急性需求 |
|---|---|---|
| 例 | 为什么你总遇到同一类人、为什么越优秀越难进入关系 | 分手走不出来、暧昧期卡住、想跳槽不敢动、低谷期、离职空窗 |
| 观众状态 | 认同、点赞、收藏，然后关掉继续过日子 | **正在痛**，痛的时候才愿意付钱 |
| 结果 | 有共鸣、无成交 | 高客单咨询 |
| 流量来源 | 只有刷到才看，没人会主动搜 | "分手""挽回""跳槽"是高频搜索词，**自带搜索流量** |

- **硬要求**：泛流量选题里，急性需求 ≥ 50%（wyh 2026-10-30 明确）。
- 慢性洞察不必全砍——它是立"十年占星师"深度的东西，急性内容立不了这个。冷启动期可以全押急性，有基础粉后补回 20–30% 慢性。
- 急性选题的流量池不比泛人群小，因为它有搜索流量。

### 3.4 双目标账号的最大风险：失焦
- 同时追"获客"和"学员"两个目标，最容易每条都想兼顾，结果一条都没落住。
- **铁律：每条只留一个落点。** 一条视频要么落咨询，要么落课程，不能两个都推。
- 配比要 **7:3 而不是 5:5**——主目标必须是获客。

## 四、内容生产公式

### 1. 素人口播三要素
**风格**（长相×语气）＋ **选题**（流量型涨粉 / 变现型获客，分开规划）＋ **场景**（画面/环境传递情绪信号）。

### ★ 开头3秒五模板（写钩子前必看）

**平台不给推流的真实原因，八成不是时长，是前 3 秒没有停留理由。** 3–4 分钟已经合理，问题在开头。

| # | 模板 | 句式骨架 | 占星场景例 |
|---|---|---|---|
| 1 | **反常识断言** | "你以为 X，其实是 Y" / "不是 X，是 Y" | "不是水逆，是你的土星在收作业"（注：慎用，土星类断言见 04 红线）｜"分手最狠的地方不是他走了，是他走的时候没告诉你为什么" |
| 2 | **身份点名** | "如果你 + 具体处境，这条你得听完" | "如果你妈每次打电话来，你看到来电显示先叹一口气" |
| 3 | **结果前置** | "先说结论：X。为什么？" | "先给结论：你不是放不下他，你是放不下那个没有答案的问题" |
| 4 | **场景切片** | "你有没有过这种时刻：+ 极具体动作" | "每次打开招聘软件，滑半小时，关掉，跟自己说再等等" |
| 5 | **自我设限** | "这条只讲给 X 的人听，其他人划走" | "这条只讲给分手超过三个月的人，还没走出来的别听" |

**写完自查三条**：
1. 这句话能不能让人**对号入座**？（要具体动作/处境，不要抽象情绪——"职场焦虑"无效，"打开招聘软件滑半小时又关掉"有效）
2. 有没有**信息缺口**？（听完想不想知道后面——断言给了结论没给原因，就是缺口）
3. 有没有**违禁元素**？（星座标签开场、播报腔、"大家好我是…"、对陌生人的命盘断言）

> 五模板可组合使用（身份点名 + 场景切片是最常用的一组）。但一条视频只用一组，不要五个都用。

### 2. 强干货四段公式（兼具流量+获客，通用）
**话题 → 钩子 → 干货 → 引导**
1. 话题：开头抛垂直人群的强场景问题（"X 到底怎么回事""怎么解决 X"）。
2. 钩子（最关键，不能话题后直接讲干货）：先说清这干货多厉害、能带来什么结果；最好放前后对比/真实案例变化。
3. 干货：拆成 1/2/3，用排比、关键词提炼，制造记忆点。
4. 引导：你有什么福利、找你有什么好处（资料/直播/1v1诊断），明确评论动作。
> 适用偏流量+获客的强干货；**高客单深度内容另用"问题解决型（70%原理+30%路径）"**，按目的选。

### 3. 高客单深度内容
- 客户买高客单前决策路径长，会大量对比、搜集信息判断你靠不靠谱；要给**一整套能颠覆认知的完整逻辑**，不是短平快爽点。
- 完播率可以很低，只要人精准——真实案例：5 分钟深度视频完播"低得可怜"，引流私域 50+、当天 3 单 1980；10 分半 3000 赞带来几十个精准客资。

### 4. 爆款复刻三步法（"洗稿"正解）
找同赛道已验证爆款 → **拆它的结构和钩子（不是抄文案）** → 填入你自己的经历/案例/观点。
- IP 的本质不是原创，是"带着你自己印记的差异化"；同一句话，你的经历让质感完全不同。翻拍别人验证过的结构，只要内核对也有流量。

### 5. AI 用法
AI 不取代你，只帮你省时间、快速产出**初步框架**；再用你个人风格、认知、经验重组成自己的东西。有稳定模型后批量输出，已超过 90% 等灵感的博主。

### 6. 执行心法
- **正确的动作重复做，做到恶心**：复盘出已验证的高收益关键动作 → 反复做；大量测试 → 找到单点 → 打爆。
- 一个阶段只锁一个目标（涨粉期只盯涨粉，变现期只盯客资）。
- 放下羞耻心：女性起号第一卡点是怕丑、怕被熟人审判；拿结果第一，美第二。

## 五、流量与平台规则

### 推流权重【观点·她转述，待核实】
2025-07 起她称的权重重排：**收藏率 > 复访率 > 铁粉深度互动 > 整体停留时长 >（5秒钩子/点赞/评论）**。
应对方向（即使权重排序有出入也成立）：
- 做**值得收藏**的干货中长视频（收藏=用户判断"以后要用"）；
- 用活人感 + 多类型内容养**铁粉**（内容先推铁粉、再推陌生人）；
- 段落化结构 + 信息密度 + 每段小钩子，拉停留与复访。

## 六、获客与变现（核心商业链路）

### 1. 高客单内容总原则
不追热点、不蹭流量密码；做非常深度的认知型内容；**不喊单、不推销、不靠过度销售**——信任到位时客户主动成交（案例：客户评论"想问问你怎么做到每天这么开心"，博主一个字没回，直接成交 10 万私董）。

### 2. 价值输出三维度（建立专业信任）
① **干货**：能直接给到对方的结果；② **行业认知**：你所在圈层、别人不知道的信息差；③ **晒交付结果**：学员结果、自己项目结果、用户好评反馈。

### 3. 公转私引流模板公式（她小号 80–90% 视频在用）
**强干货 + 人设点 + 利益点钩子**。
- 钩子话术：评论区打关键词领资料（"想要""拆解""想赚钱"），用免费高价值资料做私域入口（起号指南、脚本库、选题库、获客模板、行业拆解表）。

### 4. 完整漏斗
公域深度干货（引导收藏）→ 评论区关键词领免费资料 → 免费钩子群 / 加微信（她用「1v1诊断看号」群，仅需关注即可进）→ 低阶文档/脚本包继续建信任 → **阶梯式产品** → 高价咨询（她定价线上 4980 / 线下 9980）。

### 5. 产品阶梯
不要一上来挂高价（别人连你是谁都不知道不会付）。搭建从低价/免费资料 → 中价产品 → 高价 1v1/陪跑的阶梯，逐级建立信任与成交。

### 6. 私域节奏与粉丝规模【观点，按阶段用】
- 她大号主张：10 万粉前先做内容冲粉、别过早把粉丝导成微信好友（早期成交容易，但提前堵死长期变现口子）；过 10 万再逐步开私域。
- 她实际矩阵打法：**大号冲粉 + 工作号（变现号）强公转私承接**，是分工而非矛盾。
- 对 wyh 的用法：占星是强信任、高客单、慢决策，可更早用"深度内容+钩子群/微信"承接，不必教条等 10 万粉；按账号定位（冲粉号 vs 成交号）与阶段决定导流强度。
- 她称 10 万粉以上"没有纯自然流、免费流量递减、商业化易变形、易惹同行麻烦"，主张闷声变现——【观点】。

## 七、赛道判断方法

- **方法：不看财报/GMV，看"这个赛道现在赚钱的人是什么水平"**。赚钱者已高度卷学历卷能力 → 赛道没钱赚别进；赚钱者跟你水平差不多甚至不如你 → 值得 all in。
- 她 2026-09 判断【观点·含招生立场】：内在成长（疗愈/心理/玄学）从业者商业化只打 30–40 分，几千到一两万粉也能稳定月入 10 万，未来 1–3 年大爆发；而情感赛道已卷到需 10 万粉＋月获客 500＋电话销售逼单，普通人不宜再入。取其"判断方法"，不照搬"赶紧 all in"结论。

## 八、敏感赛道合规要点
- **敏感赛道不是靠玄学/神秘学做起来的**：是"结合人性的前端 IP 打造 + 后端服务交付、把用户拿到结果"。
- 路径参考：把"玄学"替换成用户更好理解、更安全的表达（心理、关系、自我成长、能量状态）。
- 目标客户：对金钱/财富/结果有欲望的女性；客单价与门槛高于普通女性赛道。
- 具体词表与红线见 `04_合规与占星适配.md`。
