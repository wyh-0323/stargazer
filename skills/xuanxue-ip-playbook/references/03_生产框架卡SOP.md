# 模式 B｜生产框架卡 SOP

用户给一个选题/想法（"我想讲土星回归/这段行运/某个关系模式"）时走本模式。产出**口播框架卡**，不写逐字稿。

---

## 生产流程

**0. 选题体检（先过这一关，不过就不做）**
- 这个体验，是那个配置能撑住的吗？（详见下方「选题自检」）
- 撑不住 → 直接告诉用户这条讲不实，别硬写。宁可废掉一条，不做编的。

**1. 定性**：这条是 流量型 / 人设型 / 痛点型 / 营销型？目的是拓圈还是获客？落点是咨询还是课程？
- **每条只留一个落点**，不能同时推咨询和课程。

**2. 选骨架**：从下方四种骨架里选（并列 / 收束 / 诊断 / 时间线），或按目的选强干货四段。

**3. 贴人**：用"人×内容贴合感"检查——这个角度 wyh 讲自不自然？强化差异化标签（心理硕士＋古现融合＋术语降维）。

**4. 填卡**：按下方模板输出。

**5. 过合规**：逐句过 `04_合规与占星适配.md`；重点是**零章"行为不能反推配置"**和标题层断言。

**6. 补检验说明**：框架卡末尾必须附"这条为什么这么设计"，让 wyh 能判断结构对不对，不是只能看顺不顺眼。

---

## 选题自检（这一步决定这条能不能做）

**唯一标准：从配置出发讲体验，不从困境反推配置。**

| 能做的选题 | 不能做的选题 |
|---|---|
| 月冥有硬相的人，情感记忆是全或无的 → 所以分手像被剥离 | 你不敢跳槽 → 你的土星在拦你 |
| 月土有硬相的人，被爱时先感到"要合格" | 你为什么单身 → 你的金星受克 |
| 土星回归期的人会经历什么（阶段重构，不是具体行为） | 30 岁想推翻一切 → 土星回归 |

**判据**：
1. 这个配置，在占星逻辑上**真的**会带来这个体验吗？（不是"听起来像"，是"推得出来"）
2. 同一个困境，能不能被 3 个以上配置解释？能 → 就不能指定一个。
3. 标题里有没有"你的 X 在拦你 / 决定 / 注定"这类对陌生人的断言？有 → 改掉。

**一个行为的多重来源提醒**：不敢跳槽可能来自月亮求稳、火星无力、太阳自我价值不确信、十宫空且命主星弱、水星选择瘫痪。土星只是其中之一。**遇到多因行为，宁可不写，也不指定单一星体。**

## 四种框架卡骨架

### 骨架 A｜并列型（三种/四种并列）
**适用**：一个现象有多种成因，且每种成因都能独立成立。
**结构**：钩子 → 论点1（成因A）→ 论点2（成因B）→ 论点3（成因C）→ 升华（三者其实是同一件事）→ 路径 → 收尾
**案例**：《母爱的三种形状》（月土/月冥/月海）
**注意**：并列的几项必须**同一层级**（都是月亮相位，不能一个月亮一个宫位），否则逻辑塌。

### 骨架 B｜收束型（多种卡法收束到一件事）
**适用**：现象有多种表现，但底层是同一个机制。
**结构**：钩子 → 论点1/2/3（三种表现，每种挂一个配置）→ **收束句**（三种其实是同一件事）→ 升华 → 路径 → 收尾
**案例**：《分手后走不出来》（月冥没答案 / 金冥不够好 / 八宫交出去没还 → 都在等一个说法）
**和 A 的区别**：A 是并列完给升华，B 是中段就要有明确的"收束句"把三条并成一条。

### 骨架 C｜诊断型（现象 → 多个原因 → 正确顺序）
**适用**：行业现象、技能卡点、认知误区。
**结构**：钩子（现象+数据感）→ 原因1/2/3（外部归因优先）→ 转折（"这不是你的问题，是结构变了"）→ 出路 → 路径（正确顺序）→ 收尾
**案例**：《今年塔罗师为什么集体难做》（AI/饱和/头部 → 转占星）
**注意**：归因必须**外部化优先**，别一上来就说"你不行"。

### 骨架 D｜时间线型（阶段/周期）
**适用**：行运、周期、年龄节点。
**结构**：钩子 → 阶段1（是什么、会发生什么）→ 阶段2 → 阶段3 → 收束（这个周期真正在要什么）→ 路径 → 收尾
**注意**：**只讲阶段特征，不讲具体行为预测**。讲"土星回归期会经历身份重构"，不讲"你 30 岁会想辞职"。

### ⚠️ 已废弃骨架：反转型（"你的 X 不是敌人，是你的准考证"）
废弃原因：这类反转极容易把星体美化（土星不是考官、不是公平的），且论证起点常是"行为反推配置"。**除非配置链条完全成立，不要用。**

## 口播框架卡模板

```
【选题】
【类型】流量/人设/痛点/营销 ｜ 目的：拓圈 or 获客 ｜ 落点：咨询 or 课程（只选一个）
【目标人群】具体到年龄/处境/痛点（默认 30+ 中女，避免低龄泛粉）
【开头钩子方向】（前3秒：从 01 的五模板里选一组；禁星座标签开场/播报腔）
【核心机制】一句话说清这条到底在讲什么
【核心数据/星理速查】（落座/相位/行运等——无生时不做宫位；标"配置方向提示"）
【论点段落】
  论点1：2-3行 + 金句
  论点2：2-3行 + 金句
  论点3：2-3行 + 金句
【升华】（收束全篇，一句话）
【路径】（30% 给行动，必须实，不能是鸡汤）
【收尾方向】（引导动作：评论关键词领资料；软钩，不硬推课）
【演绎注意】（语气、留白位置、不能滑向哪里）
【合规自检】（命理词软化 / 有无断言 / 有无12星座清单 / 配置是否撑得住）
【这条为什么这么设计】（4条检验说明，让 wyh 判断结构）
```

## 钩子与引导素材库
- 免费资料钩子：行运自查清单、配置解读模板、某关系模式自测、看盘判断顺序、转型迁移清单。
- 评论口令设计：一个好记的关键词（自查/月亮/结构/升级），对应自动/私信发资料。
- 强干货开头："到现在还不会做深度内容的人，不可能获得高端客户"式的强断言＋案例引入。

## 选题从哪来
- 从**真实咨询/学员案例**来（脱敏）：客户反复问的问题就是痛点型选题。
- 从**已验证爆款复刻结构**来：拆结构和钩子，填自己的案例与观点，不抄文案。
- 同一深度结构**平移**到不同载体：星盘配置 / 行运 / 月相 / 关系合盘 / 星宿 / 日主。
- 痛点型自检：讲完之后，对的人会不会觉得"这说的就是我，我想找她解决"？
- **急性优先**：泛流量选题里急性需求要占一半以上（见 `01_核心模型速查.md` 3.3）。
