# 合规红线 × 占星赛道适配（任何产出必过这一关）

## 零、最高红线：行为不能反推配置

**这是最容易犯、也最致命的错。** 违反它，内容会同时踩两条线：占星逻辑错 + 平台违规（对陌生人下命盘断言）。

### 错误方向（禁止）
```
观众的行为/困境  →  反推  →  你是什么配置
```
例：「你不敢跳槽」→「你的土星在拦你」。
这是算命话术，不是占星。一个行为可能有五六个来源，直接指定一个星体，既不准也违规。

### 正确方向（必须）
```
配置  →  讲这种配置的人会怎么运作（体验层）
```
例：「月冥有硬相的人，情感记忆是全或无的」→ 讲这种运作方式带来的体验。
**先有配置，后有体验。不能倒过来。**

### 三个具体错例（都是真实踩过的坑）

**错例 1｜把星体简化成一个情绪词**
- ❌ 土星 = 恐惧 / 资格感 / 审判者
- ✅ 土星 = 限制、结构、时间、责任、边界、延迟、权威。恐惧只是它受克时的一种表现，不是它的定义。
- 病因：心理占星的通俗化说法（"土星是严父"）可以说，但不能拿来定人。

**错例 2｜从宫位硬推行为**
- ❌ 土星落十宫/六宫 → 不敢跳槽
- ✅ 土星落十宫更常见的是**事业心重、责任大、大器晚成、扛得多**；落六宫是**工作繁重、日常消耗、健康注意**。方向甚至可能相反。
- 病因：把"宫位领域"当成了"行为预测"。

**错例 3｜美化星体**
- ❌ "土星是唯一一颗付出就一定有回报的星"
- ✅ 土星讲的是**应得**，不是**赐予**（赐予是木星）。土星受克（落陷、逆行、被凶星刑克）时，付出未必有回报，可能只是加倍的消耗。
- 病因：为了让内容"有希望"，把星体的凶性抹掉了，这是失真。

### 一个行为的多重来源（举例：不敢跳槽）
月亮极度求稳（安全感缺失）／火星无力（火土相位、火星落陷逆行、火星被压制）／太阳自我价值不确信／十宫空且命主星弱／水星过度分析导致选择瘫痪／木星弱（缺乏扩张信心）。
**土星只是其中之一，而且往往不是主因。**

### 产出前自检三条
1. 这条的每个论点，是不是**先有配置、后有体验**？顺序反了就重写。
2. 把配置抽掉，论点还成立吗？成立说明配置只是装饰，不叫占星内容；不成立才说明配置是骨架——但仍要检查这个骨架是不是真的撑得住。
3. 观众没给出生时，**标题和钩子里有没有出现"你的 X 在拦你 / 你的 X 决定了"这类断言**？有就改掉，改成"有这种配置的人"。

### 标题层的额外红线
- ❌ "你的土星在拦你"、"你的月亮决定了你会遇到谁"——对陌生人的命盘下断言，平台最敏感这条线。
- ✅ "土星型的人，在面对变动时会怎么运作"、"有这种配置的人，为什么总在最后一刻退缩"。
- 断言 + 引流（"你的 X 卡在哪，评论区打 Y"）是双重违规，绝对不能组合使用。

## 一、平台合规表达转换表
把"神秘学断言"改写成"心理成长/自我觉察"框架——既保留吸引力，又不踩封建迷信限流。

| 高风险表达（少用/不用） | 安全改写方向 |
|---|---|
| 改运、转运、改命 | 调整状态、改变选择、自我成长带来的变化 |
| 正缘、孽缘、烂桃花 | 健康的关系模式、消耗型关系、关系中的自我觉察 |
| 招财、破财、财运 | 与金钱的关系、财富思维、资源与机会 |
| 驱邪、消灾、挡煞 | 情绪疏导、压力释放、心理重建 |
| 命中注定、你注定会… | 你的模式倾向是…、你更容易…、可以选择… |
| 恐吓式（不怎样就会怎样） | 中立呈现模式 + 给选择权 |
| 12 星座逐座许愿/运势清单 | 心理机制类内容、通用成长主题（红线，禁做） |
| 挽回、必复合、教你挽回他 | 只讲"为什么越努力越远"的机制，不给关系结果承诺（"挽回"词本身踩情感咨询资质+迷信承诺双线） |

原则：
- 天象、命理内容**优先心理向**：讲"这股能量/这种配置对应什么心理议题、可以如何自处"，不下宿命结论。
- 不点名在世名人做命理断言、不蹭纠纷热点（通用科普红线）。
- 原生家庭类只讲通用模式、立场中立导向和解，不武断断言某个真实当事人的事实。
- 高客单也不许诺"包好/改命/必复合/必挽回"。

## 二、占星硬内容边界（铁律）
- 本 Skill 只产出**结构、人性洞察、表达框架**，不替用户生成未经核验的排盘结论。
- 凡涉及真人盘/天象/类型盘的**落座、相位、宫位、角轴及心理结论**，必须由伽兹实跑落档、成稿过伽兹复核；海螺不发源、不补骨架、不猜配置。
- **无精确出生时间不做宫位判断**，相关表述全程用"大概率/有可能"。
- 认知/观点/方法论/价值观类稿子不需要伽兹；日月升金火管辖域等入门常识可自行把关。
- 默认排盘容许度 6-4-5-5-5；名盘分析以相位为骨架、落座为背景，禁止仅靠星座推导。
- **框架卡里的配置一律标"配置方向提示"，不是断言**；演绎时用"有这种配置的人"，不用"你一定是"。

## 三、内容立场原则：不否定目标客户

写学员入口型 / 转型引导型内容时，**姿态决定转化**。

| 错误姿态（把人推走） | 正确姿态（招得到人） |
|---|---|
| "十个塔罗师八个学不会占星" | "塔罗师转占星，不是转行，是升级" |
| 指出对方的不足 | 先认可对方已有的能力，再说要补什么 |
| "你卡在哪" | "你缺的不是能力，是换系统" |
| 居高临下的诊断 | 同行视角的引路 |

原则：
- **目标客户是谁，就不能否定谁。** 面向塔罗师的招生内容，不能说"塔罗师学不懂占星"。
- 讲差距时，定性为**系统差异**，不是**能力不足**。
- 劣势要先转成优势再讲（"你已经相信符号能对应现实，这是零基础最难跨的门"）。
- 归因外部化：行业变难时，先归到 AI、饱和、头部垄断这些结构原因，再说"这不是你的问题"。
