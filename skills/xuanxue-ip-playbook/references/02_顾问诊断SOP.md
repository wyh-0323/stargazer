# 模式 A｜顾问诊断 SOP

用户给出现成账号、内容、数据或困惑（"我的号为什么不涨粉/不来客/这条视频行不行"）时走本模式。

## 六步审计
1. **定位贴合度**：对照"人×内容贴合感"和二维矩阵——她的气质、表达和所做话题是否一致？玄学号是否落在"冷感×唯心"或她真实贴合的象限？人设是在"演"还是"长"？
2. **内容类型**：把她现有内容分成 情感共鸣型 / 问题解决型。若绝大多数是"是什么/情绪共鸣"，指出来客低龄、低客单的直接原因，并给一个同选题的"问题解决型"改写示范（70%原理+30%路径）。
3. **选题结构**：用四类内容（流量/人设/痛点/营销）盘点配比，指出是否只有流量没有痛点/营销，或一上来就硬卖；给出 60-70% 拓圈 + 30% 变现的调整建议。
4. **单条结构**：抽查代表作是否具备 话题→钩子→干货(3点)→引导；钩子有没有"结果/对比"，结尾有没有明确动作。
5. **获客链路**：公域是否有钩子（评论关键词领资料）→ 承接（群/微信）→ 低阶信任产品 → 阶梯产品。缺哪环补哪环。
6. **合规**：过 `04_合规与占星适配.md` 词表，标出迷信/宿命/恐吓表达并给改写。

## 输出格式
- **一句话诊断**（最核心的 1 个问题）
- **证据**：引用她提供的具体内容/数据，不空泛
- **优先动作**：至少 2 个可立即执行、可验证的动作（按性价比排序），每个动作说明"做什么 + 对应哪条模型 + 怎么判断有效"
- 涉及平台权重/趋势判断时标注"经验判断，非官方规则"
- 不替她生成未经伽兹核验的星盘结论

## 常见病症对照表
| 症状 | 最可能的根因（先查这个） |
|---|---|
| 有播放不涨粉/来的人很泛 | 内容是情感共鸣型/纯知识点，没有筛选精准客户 |
| 点赞高但没人咨询 | 缺痛点型内容 + 缺明确钩子和承接 |
| 来的都是低客单/学生 | 话题方向太低龄，没有"为什么+怎么做"的深度 |
| 一卖货就掉数据 | 营销型比例过高/上来就高价，缺信任阶梯 |
| 拍得很用力但不爆 | 人×内容不贴合，或在复刻文案而不是复刻结构 |
| 玄学内容被限流 | 踩了神秘学/宿命/恐吓表达，按合规词表软化 |
| 不敢开始/怕被熟人看 | 心态卡点：结果第一、美第二，先跑量再收敛 |
