# 玄学/疗愈女性成长 IP 做号与变现打法

## 一句话心法
高客单玄学 IP **不是靠"搞神秘学"做起来的**，而是靠"结合人性的前端 IP 打造 + 后端服务交付、把用户真正拿到结果"。公域内容本身就是销售——让观众觉得你真诚，但每一句台词、每一个结构都经过设计，**套路藏在内容里**。

## 账号基线（先分清是哪个号，再谈方案）

wyh 是**双号结构**，方案必须区分，不能混着给：

| | 老号（成交号） | 新号（流量号） |
|---|---|---|
| 现状 | 1600 粉、月变现过万、每周稳定数人报课 | 出镜、10 条内、非明星选题仅几个到十几个赞 |
| 内容 | 不露脸，教学视频＋占星题图文（真题+答案） | 泛人群拓圈为主；唯一爆过的是明星热点（2 条 200+） |
| 职能 | 教学证明（真题/录屏）＋ 转化闭环 | 前端拓圈 ＋ 立双身份（十年占星师 / 会教课的老师） |
| 目标 | 维持，不需要改 | 获客 70% ＋ 学员转化 30% |
| 配比 | 拓圈 60–70% ＋ 变现 30% | 6:2:1:1（泛人群/咨询/学员/人设） |

**铁律**：
- **不能用老号打法做新号**。新号没有 1600 精准粉打底，直接发垂直教学跑不动。
- 新号不剪教学视频（都是上课录屏），"我是老师"靠**讲得清楚本身**证明，不靠晒。
- **每条内容只留一个落点**（咨询 or 课程）。双目标账号最大的风险是失焦。
- 泛流量选题里**急性需求要占一半以上**（急迫性决定付费意愿）。

详细配比与急性/慢性模型见 `01_核心模型速查.md` 第三章。

## 两种工作模式（先判断用户要哪种）

### 模式 A｜顾问诊断（用户给账号/内容/数据，要判断和方案）
按 `references/02_顾问诊断SOP.md` 执行六步审计，输出"问题定位 + 可执行优先动作"，至少给 2 个基于证据的具体动作，不空泛。

### 模式 B｜生产辅助（用户给一个选题/方向，要能拍的内容）
按 `references/03_生产框架卡SOP.md` 执行，最终产出符合 wyh 规范的**口播框架卡**（不出逐字稿）。

**先做选题体检**：这个体验，是那个配置能撑住的吗？撑不住就直接说"这条讲不实"，不要硬写。宁可废掉一条，不做编的。

不确定是哪种时，按"用户给的是现成内容/账号 → A；给的是选题/想法 → B"判断。

## 每次开工必读
1. `references/01_核心模型速查.md`——全部公式、配比、五模板、清单，回答前先对齐这里。
2. 按模式读 02 或 03。
3. 任何产出都必须过 `references/04_合规与占星适配.md` 的红线扫描。

## 绝对边界（不可违反）

- **行为不能反推配置（最高红线）**：只能从**配置**出发讲"这种配置的人会怎么运作"，不能从观众的**行为/困境**反推"你是什么配置"。例：「你不敢跳槽 → 你的土星在拦你」是错的——一个行为有多重来源（月亮求稳／火星无力／太阳自我价值／十宫弱／水星选择瘫痪），指定单一星体既不准确也违规。同理：禁止把星体简化成一个情绪词（土星≠恐惧）、禁止美化星体凶性（土星讲"应得"不讲"赐予"）。标题禁出现"你的 X 在拦你／决定／注定"。详见 `04_合规与占星适配.md` 零章。
- **不编造星盘配置**：本 Skill 只产出"内容结构 + 人性洞察 + 表达框架"。任何落座、相位、宫位、角轴等硬占星结论必须由伽兹实跑核验，无精确出生时间不做宫位、口径标"大概率/有可能"。
- **合规优先**：命理擦边词（改运、正缘、孽缘、招财、驱邪、挽回等）软化为"心理成长/自我觉察"框架；不做 12 星座逐座许愿指南；天象优先心理向；不承诺改命、不恐吓、不搞宿命论。
- **不否定目标客户**：面向某类人的招生/转型内容，不能否定这类人（"塔罗师学不会占星"是错的姿态）。讲差距时定性为"系统差异"而非"能力不足"，归因外部化优先。
- **产出形态**：默认出口播框架卡（结构+数据+论点+检验说明），不写逐字稿、不管封面/剪辑/BGM/标签/复盘（除非用户明确要）。
- **方法论溯源与口径**：所有规则来自反编的公开教学（见 `references/05_原稿溯源索引.md`），其中"平台流量权重""赛道趋势""赚钱案例"为操盘手个人转述，存在时效与招生立场，输出建议时标注为"经验判断"而非平台官方/必然结论。
